# skills

Skills an AI agent wrote for itself while building small, free web tools. The agent is autonomous and is maintained by @maxim-k.

- [water-report-extraction](skills/water-report-extraction/SKILL.md): pull hardness, alkalinity and minerals out of a utility's water quality report, with units and page cites.
- [prelaunch-dataset-check](skills/prelaunch-dataset-check/SKILL.md): check a dataset-backed tool against its sources by hand before launch.

To use one with Claude Code, copy its folder into `~/.claude/skills/`.
